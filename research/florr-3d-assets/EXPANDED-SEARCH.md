# 2n / Florr 3D Resource Gate — expanded search

Date: 2026-09-24. Research only. No Hero, Garden, camera, narrative, production asset, or deployment changes. The separate review gallery still contains only the original eight GLBs and 13 SVGs; it has **not** been expanded with the resources below.

## Correction to the earlier audit

The eight [3dflorr public GLBs](https://github.com/meh-a/florr3d-public/tree/main/client/assets) are primarily Garden insects and ants. Their project-specific `map.json` is **not** the whole Florr world. A different fan map project has five separate, more comprehensive biome maps. No additional verified ready-to-use Florr-specific non-Garden GLB was found in this pass; images, map data, and SVGs are **2D reference material, not 3D assets**.

## The five previously uploaded screenshots

Located the five original uploads from 2026-09-05 and identified them visually: Garden (bright green), Desert (sand/beige), Ocean (blue), Jungle (deep teal-green), Hel (red). The earlier 2n repository also contains processed `dist/assets/{garden,desert,ocean,jungle,hell}.png` images (1504 × 1046). These are the primary user-provided visual *references* for subsequent art direction; they are screenshots of Florr, not a license to redistribute game artwork. Do not assume every original 2D background can be used as a public site texture without checking rights. The screenshots and production site remain untouched.

## Gaps and feasibility

- **Flower / player body:** no externally verified high-quality, ready-to-license Flower 3D GLB found. The procedural substitute in 3dflorr is not an original model file. A purpose-built, lightweight Flower with face and Petal orbit is likely needed, after art direction and rights review.
- **Mob GLBs:** only the previously audited Garden/ant-family eight GLBs are presently verified. None of the linked Desert/Ocean/Jungle/Hel mobs above is a 3D asset. File size, triangles, animation, textures, and compression for hypothetical new models are **unknown**; do not claim iPhone readiness.
- **Biome geometry:** five `.tmj` maps and 115 SVGs provide concrete tile vocabulary and layout references. Translating them into original, low-draw-call 3D environments requires deliberate modeling, not direct client extraction or copying copyrighted art.
- **Licensing:** public access to screenshots, Wiki, maps, or icons is not a grant for website display or derivative modeling. Obtain explicit permission for direct reuse, or commission/create independently authored forms while addressing Florr IP and fan-site permission separately. Prior CC BY-NC 4.0 Garden files remain conditional; do not call them fully cleared.
- **Mobile budget:** design candidates for reusable low-poly mesh/instancing, opaque materials, restrained texture sizes and transparency, few dynamic lights and shadows; measure on a real iPhone Safari only after a separately approved review prototype. No performance test was run this research pass.

## Screening decision, not asset selection

**HIGH VALUE for art direction:** user screenshots, the five fan map layouts and 115 SVG tile vocabulary, broad Petal/Mob silhouette atlas. **POSSIBLE for conditional direct use:** the eight Garden/ant GLBs under repository CC BY-NC 4.0 only if upstream provenance and site noncommercial status are resolved. **REFERENCE ONLY:** all screenshot/map/tile/icon art with unresolved original game rights. **REJECT for adoption:** empty/same-content forks as separate model sources, unrelated generic realistic biome packs as Florr identity, client extraction, and any claim that a 2D icon is already a mobile-ready GLB.

No new preview deployment was created. Existing separate review preview: https://florr-3d-asset-review-2n.llhleo.chatgpt.site/ (the previous Garden-only set, **not** the expanded findings).
