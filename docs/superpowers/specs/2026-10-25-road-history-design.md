# 道路历史接入

延续已审阅的 v11 三幕实际渲染与接入方案，并执行用户本轮明确要求：新分支、原站内接入、独立 Site 预览。main 和原 Site 不发布。

- 人物长链之后、原粒子结尾之前，以连续摄像机路径穿过三幕；不使用遮罩或场景切换。
- 沿路平均间距约 v11 的 1/3，使用有最小安全距离的种子随机间距；双车道反向行进。扩充到原站真实 PETAL 模型，保持材质和展示面。
- 三个光珠共用圆滑闭合轨道，只有相位不同；发光核心、渐细光尾、邻近表面受光，全部保留深度测试。
- 环境时钟独立：道路花瓣、空间花瓣、光珠、2n 潮汐背景，在摄像机行进、倒放、静止时都继续运动。
- 仅新三幕道路的36秒章节中，手势触发播放方向和目标段落；首屏、五境、回望、人物、后续粒子结尾使用原来的滚动控制。道路段内，运行速度由秒数决定；一次手势最多推进一段，不按滑动距离或速度直接采样画面。倒滑从当前画面平滑反向，不跳回旧 scrollY。
- 保留原站五境、人物事实、三条历史记录、现有粒子结尾的数量和动作。第三幕使用真实 unique 事件，不虚构具体花瓣，不再额外设置 2n 雕塑。

实施选择：沿用 Three.js r180、原 renderer、stableViewport、原模型加载流水线。花瓣实例化并在场外循环，字线合并后在 GPU 变形。正式视觉字体使用已修复的非零绕组轮廓三角化；正文如需换行使用原本地字体。

对比方案：直接 scrollY 采样会使猛滑闪过；单纯限速仍会造成队列积压。本版使用限一段目标的时间播放器，手势释放后播放至该段终点并停留。用户要求已有明确方向，无需重新选方案。

验收：方向与速度独立、快速反向、触控惯性、边界与重播、10 分钟循环花瓣密度、字体和道路完整、光珠遮挡、原构建和原测试回归。Safari 实机验收单独记录。
