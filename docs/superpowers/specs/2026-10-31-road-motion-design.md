# 道路故事运动与空间修订

按用户七项截图反馈执行，更新既有预览和 feature 分支。滚动范围仍只有新道路章节采用手势定时播放。

- 沿路交通使用共享、始终为正的呼吸速度；平均约原来的 2.3 倍，快慢周期连续，不能逐个随机加速造成追尾。
- 由道路宽度和最小间距约束随机半径，整体增大。两向车流在深度上分层，增加轻微连续横向游弯；仍跟随同一实体路面参数。
- 文字保持真实字体轮廓，放大日期、标题和正文，三幕各选空白区域。第二幕拆标题并采用渐窄正文，避免主路穿过阅读区域。
- 结尾移到道路侧面的独立空间。镜头沿连续弧线离开第三幕；真实花瓣沿疏密错落的曲线引向粒子空间，不提前显示旧球壳。花瓣面向实际渲染镜头，过渡与停留都有独立环境时钟。
- 原粒子数量、材质、聚合动作、原生滚动映射不变。新路段的末端花瓣不能侵入粒子画面形成近乎静止的装饰。
- 保持模型、分辨率、字体、字线、粒子质量；优先减少实例矩阵上传范围、缓存曲线和静态变换，测量 CPU 与上传量。性能结论必须区分 CPU 测量与 Safari 实机。

实现取舍：逐花瓣随机速度会破坏间距，采用共享速度积分和独立小幅横摆；直接淡出远处球壳仍有漂浮队形感，改为空间分离和真实引导流；不通过减模型或降低像素比获得性能数字。

本轮执行选择由用户明确的修改请求与现有预览授权决定，无需再次征求实装许可。外部设计检索当前不可用，采用现有品牌和截图约束。
