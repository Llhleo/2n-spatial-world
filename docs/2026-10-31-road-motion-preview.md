# 道路故事预览修订

基于用户四张 iPhone 截图和七项要求，延续 `feat/road-history-gesture-playback`，只发布独立道路预览。

## 最终实现

- 道路花瓣平均速度由 2.8 提至约 6.4 单位/秒；同一道路共享连续呼吸速度，避免随机加速追尾。种子随机尺寸整体增大，保持原密度和随机间距。
- 车道内小幅双频游弯，由同一路面参数的横向导数确定；反向车道有深度分层。前景悬浮花瓣加快独立曲线运动，并前移到与路面交通分离的深度。
- 日期 32→44、正文 30→36、标题 49–64→78–84（864×1872 设计坐标）。三幕重新选择阅读区，第二幕拆题并逐行收窄正文。原 Noto 轮廓字体与非零绕组处理保留。
- 粒子空间位于道路坐标的 `[-620,80,-1650]`，镜头沿缓存弧线进入侧面空地。旧远处球壳替换为连续纵深花瓣流，面向真正渲染的镜头。新路段接入的粒子伴随花瓣在停留时也持续运动。
- 原生滚动的范围不变；只有新道路 36 秒使用手势定时播放。粒子数量 262144、原聚合时间与材质保留。
- 每帧只上传可见实例矩阵；静态 Mesh 变换、转场曲线和同路速度积分复用；离开人物入口后跳过不可见捕获链的矩阵更新。没有降低模型细节、像素比或粒子数。

## 验证

- 全部 Node 测试：386 通过，0 失败。
- 真实道路 + 花瓣球包围体：600 秒，0.5 秒采样，7,000,584 对检查；0 相交，最小静态余量 0.544，线性扫掠余量 0.500。它是有限时间的保守包围体采样，不是连续三角形碰撞证明。
- 字体：21 条实际使用的文字，最小原字体栅格 IoU 0.9526。移除旧换行的未使用轮廓，所有可见轮廓数据与重建前逐项相同，文件约 963KB（上一版约 1050KB）。
- 414×896：9 个阅读镜头、630 个文字采样点，无道路遮挡或越出安全视口。
- 粒子开头至结尾的采样镜头，不再显示道路交通实例；道路/粒子边界摄像机位置误差 <1e-9。
- 一个道路定机位 CPU 微基准：中位约 1.7ms，未据此声称手机帧率提升。可见 103 个实例时，分配的矩阵缓冲 578240B，常规每帧更新 6592B，约减少 98.9% 上传量；首次缓冲分配仍需完整上传。
- 构建通过；现有 Vite 大 chunk 提示仍在。
- 当前云端浏览器不支持 WebGL2，因此未完成实际 GPU 画面、Safari 实机帧率与触控复验。
