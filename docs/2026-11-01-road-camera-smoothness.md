# 公会故事镜头轨迹检查

当前成功预览版本首先备份到 GitHub 新分支 `feat/road-camera-smoothness-20261101`，初始提交为 ad81c620e9d787ad99f3a56d93987518c86f4eab。此后该分支保存本轮检查与修复，不改 main。

## 发现与修复

- 原路径虽然位置连续，但由分段 Catmull 曲线及低分辨率弧长表驱动，内部弯点有速度尖峰；36秒路线以240Hz采样，最大位置加速度约30698、最大角加速度约112.91。
- 两次场景切换、退场镜头改为单段多项式空间曲线，沿原控制点所定义的走廊圆滑转弯；弧长表提高到4096段。实体道路、文字、花瓣和36秒时序均保留。
- 进场保留原路径点及中间切线，使用五次插值使控制点两侧加速度连续，避免控制点处顿挫。
- 过场朝向以相邻阅读镜头的四元数衔接为基础，保留受平滑包络限制的道路导向转头；避免靠近导向点时突然大幅偏航。阅读构图、首尾位置/朝向/视角保持一致。

## 验证

- 新增240Hz整段正放/倒放轨迹检查，并校验进场路径点、所有章节边界的位置/朝向/视角和加速度衔接。
- 同样采样下最大位置加速度约1904、最大角加速度约4.78；这是CPU轨迹数值，不是Safari帧率或视觉保证。
- 道路实体、远端路口、灯光、横竖屏、长时间停留及粒子入口衔接的已有检查通过。完整406项测试及生产构建通过，41份模型传输文件保留。
- 当前环境无法验证WebGL2实际渲染画面，iPhone Safari最终观感仍需实机复查。
